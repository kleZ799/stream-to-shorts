No more black windows. A pause button. And a clips folder you can actually read.

## The flashing windows are gone

ffmpeg — the tool that does the actual cutting — is a console program, and a windowed app starting one makes Windows open a console for it. A long render meant dozens of black windows blinking open and shut.

Nothing was ever wrong. But an unsigned exe spawning unexplained console windows looks exactly like something you should not have downloaded, and several people said so. They are hidden now.

## Pause

Rendering takes every core it can get, and until now the only way to get your machine back was to kill the run and lose the work.

**Pause** stops the work where it stands — ffmpeg is suspended, not asked to finish the current clip first — so the CPU comes back immediately. Resume continues from exactly where it stopped. Nothing is lost and nothing is redone.

One limit worth stating: during transcription the work happens inside the app rather than in a separate program, so a pause there takes effect at the next step instead of instantly.

## The clips folder makes sense now

It used to be folders called `0f83f76b5623`, with downloads beside them called `source_dQw4w9WgXcQ.mp4`. Correct for the code, useless for a person trying to find the clips from one particular video or work out which multi-gigabyte file is safe to delete.

- **Run folders** are now the **video's title and the date**.
- **Downloads** are named after the video too, with its id in brackets.
- **A short note** in the folder explains what each part holds, what is safe to delete, and what to leave alone.

Upgrading does not re-download anything — files saved under the old names are still found.

## "Windows protected your PC" — explained, in the app

The first thing a new user sees is a warning, and the app used to say nothing about it.

The help section now explains that the exe is unsigned, that a certificate costs money this project does not take, and that SmartScreen is reporting a missing signature rather than a finding. Then what can be checked instead of taken on trust: the source is public, the exe is built from it by GitHub's own servers with a readable log, every release publishes a SHA-256, and the app works with the network off.
