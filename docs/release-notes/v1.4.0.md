v1.3.2 put the author in the masthead. That is attribution, but at 30px in a corner it is not an introduction, and someone who has just installed an unsigned exe from the internet deserves one.

**Built by [Parth Bhadana](https://github.com/kleZ799)** — [YouTube](https://www.youtube.com/@ParthBhadana799) · [GitHub](https://github.com/kleZ799) · [LinkedIn](https://www.linkedin.com/in/parth-bhadana-530014202/) · [Source](https://github.com/kleZ799/stream-to-shorts)

There is an email address on it too, which copies to the clipboard when clicked rather than firing a `mailto:` at a machine that may have no mail client set up.

It closes on Esc, on the backdrop, and on either of its own buttons. Dismissing it is not remembered — it greets you every time — but the credit line in the sidebar is now a button that opens it again whenever you want it.

Nothing about it is English-only. The whole card is translated into all six languages the app already speaks.

## The upgrade you are reading about actually arrives

A quieter fix, and the reason this release matters more than its feature list.

Nothing sent a `Cache-Control` header for the interface files, which leaves a browser free to invent its own freshness window — and it does. The packaged app keeps its WebView2 cache across versions and has no reload button anywhere in the window, so it was entirely possible to install a new build, launch it, and keep running the **old** interface out of cache with no way to tell.

If you have run any earlier version, that bug is why you might not have seen a change you were expecting. It is fixed from here on.

## Also in this release
